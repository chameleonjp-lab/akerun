# 写実素材

このフォルダのWebPは、操作中に変化しない金属面の下地です。

- `vault-door.webp`: 金庫扉と扉側の機械的な下地
- `vault-dial.webp`: 真鍮ダイヤルのベース
- `lock-cutaway.webp`: 6ホイール内部機構の下地

ダイヤルの目盛り・現在値・ホイール位置・フェンス・ボルト・状態表示は、正確な操作状態を保つためCanvasで描画します。画像へ操作状態を焼き付けないでください。

現在の3枚は、リポジトリに存在しなかった旧画像の代替として作成した初期素材です。元画像が提供された場合は、同じファイル名へ差し替えるだけで、VaultWorld.tsの参照と動作を維持できます。

配信前に次を確認してください。

- 画像を毎フレーム生成・転送していない
- 画像が読み込めなくてもCanvasのフォールバックで操作できる
- 390×844、402×874、430×932、768×1024で文字と操作範囲が崩れない
