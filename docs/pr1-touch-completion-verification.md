# PR1：後半のタッチ操作と初期化復旧

2026-09-08の監査・改善実装計画に基づく最初の変更。対象はF01・F02・F05・F09。
基準mainは `22dd36d29aedc1b6030d2af2bc418992a1028b22`。

## 変更と根拠

| 対象 | 起きていたこと | 修正 |
|---|---|---|
| F01 | readyからtestへ進んだだけで指が解除され、保持が続かなかった | 操作する部品が同じ間は入力を維持。別部品への成功遷移・開錠・安全停止では解除する |
| F02 | 扉ハンドル段階がメモ表示へ分岐し、部品と操作領域を登録しなかった | 作業台の分岐を明示し、ハンドルの描画と操作領域を登録する |
| F05 | 回転した金色の握りと操作領域の位置がずれていた | 描画と同じ角度・長さから握りの座標を求め、操作領域に含める |
| F09 | Canvas初期化の失敗をコンソールにしか出さず、再試行できなかった | エラー案内と「もう一度試す」を表示し、初期化単位でループ・リスナー・入力を破棄する |

初期化の処理は `GameCanvasLifecycle.ts` にまとめた。初期化中の背景移行と、アンマウント後に初期化が完了する場合も扱う。初回描画で失敗した `VaultWorld` は入力リスナーを破棄してから例外を返す。

エラー案内には標準のモーダルdialogを使い、背面へ操作が抜けないようにする。保存処理は変更していない。

周回ルール、停止判定、公式問題、採点値、共有再生、ランキング保存先はこのPRの対象外。監査で見つかった判定・記録の課題はPR2へ引き継ぐ。
