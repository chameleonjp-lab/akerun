# PR3：モバイル表示と操作領域

2026-09-08の品質監査・改善計画に基づく変更。対象は、スマートフォンでの
「現在の操作」の可読性、横画面の実寸レイアウト、Canvasとポインター座標の一致。
ルール、採点、操作履歴、保存・ランキング契約は変更していない。

## 変更内容

| 対象 | 起きていたこと | 修正 |
|---|---|---|
| 横画面の座標 | 874×402の画面でも論理Canvasを520px高として描き、CSSで縦に縮めていた | 実寸が取得できた場合はその幅・高さを論理座標へ使用。初期化直後の0/NaNだけ320×520へフォールバック |
| 短い横画面 | ダイヤル下のCanvasレールと作業台が下端からはみ出しやすかった | 短い横画面用の半径・位置を計算し、Canvasレールを省いてHTMLメニューを左下へ一列配置 |
| 行動の読み取り | HUDは段階名と短いメッセージだけで、輪・方向・通過回数を追いにくかった | スナップショットへ安全な表示情報を追加し、HTMLの「現在の操作」へ輪・方向・目標（表示許可時のみ）・何回目・停止確認を表示 |
| 小さい文字 | 縦長機構ストリップの見出し・輪番号が7px前後になっていた | ストリップを2行見出しへ変更し、見出し・輪番号を14px基準へ拡大。長い操作説明はHTMLへ移した |

隠し難度では、正解目標・担当輪・方向・通過回数をスナップショットから除外し、
「音と振動の合図を聞いて操作します」という表示だけを返す。標準・専門でも
正解位置は表示せず、反応から探すことを明示する。
